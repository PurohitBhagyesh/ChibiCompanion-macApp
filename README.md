# ChibiCompanion-macApp
🐾 A cute interactive desktop companion app for macOS, built with Swift, SwiftUI &amp; AppKit.

Chibi Companion is a small macOS app designed to bring an animated companion directly onto your desktop.

✨ Features

* 🐾 Animated desktop companion
* 🖱️ Cursor interaction
* 🎭 Different behaviors
* 🏃 Multiple movement speeds
* 🎞️ Animations
* 🔊 Sound effects
* ⚙️ Custom settings
* 🖥️ Built specifically for macOS
